# Security

Only the latest release is supported. The runtime performs no network requests and never
executes input content. Diagnostic output may still identify machines, devices or local
paths. Inspect reports before sharing them. Resource limits reduce accidental oversized
input; they are not an isolation boundary for hostile files.

Use [GitHub private vulnerability reporting](https://github.com/KanadeK/journal-offset-map/security/advisories/new).
If that facility is unavailable, open an issue requesting a private contact channel without
including vulnerability details or sensitive data. Ordinary malformed-input bugs may be
reported using a minimized synthetic reproducer.
